✅ 목표 구조 (멀티 사용자용 정답)

여러 사람이 동시에 쓰려면 구조를 이렇게 바꿔야 합니다:

        ┌──────────────┐
        │   SERVER DB   │  ← “진짜 점수”
        └──────┬───────┘
               ↑   ↓
     fetch/load_score.php
     fetch/save_score.php
               ↑   ↓
        ┌──────────────┐
        │   모든 사용자 │
        └──────────────┘
🧠 핵심 개념 3개
1️⃣ 상태는 JS가 아니라 서버가 가진다

👉 teamA, teamB는 서버 기준

2️⃣ 클라이언트는 “표시 + 요청만”
+1 클릭 → 서버에 요청
서버가 계산 → 다시 반환
3️⃣ 일정 주기로 동기화 필요

👉 실시간처럼 보이게 polling
